# Система учета реактивов и склада лаборатории (ЛР2)

Проект представляет собой десктопное приложение для управления лабораторными реактивами, их партиями (бутылками) и складскими остатками. Приложение разработано на Java с использованием технологии JavaFX для графического интерфейса.

Данная версия проекта соответствует выполненной **Лабораторной работе №2**.

-   **Предметная область:** 2 (Реактивы и склад).
-   **Вариант хранения данных:** 3 (CSV).
-   **Вариант пользовательского интерфейса:** 3 (Карточки).

## ✨ Возможности

-   **Управление реактивами:** Добавление новых химических реактивов с указанием названия, формулы и CAS-номера.
-   **Учет партий:** Создание партий (бутылок) для каждого реактива с указанием метки, количества, единиц измерения и места хранения.
-   **Визуализация данных:** Просмотр списков реактивов и партий в виде удобных информационных карточек.
-   **Сохранение и загрузка:** Возможность сохранять все данные в файл `data.csv` и загружать их при следующем запуске.
-   **Ручное обновление:** Актуализация данных на экране происходит по нажатию кнопки "Refresh".
-   **Безопасность ввода:** Валидация данных на уровне бизнес-логики с выводом понятных сообщений об ошибках.

## 🏗️ Архитектура и принципы

Проект разработан с соблюдением принципов многослойной архитектуры для четкого разделения ответственности:

-   `domain`: Классы сущностей (POJO), описывающие предметную область.
-   `repository`: Слой доступа к данным (in-memory хранилище на основе `LinkedHashMap`).
-   `validation`: Валидаторы для проверки корректности данных перед их сохранением.
-   `service`: Бизнес-логика приложения, координирующая работу между репозиториями и UI.
-   `storage`: Слой, отвечающий за сохранение и загрузку данных в CSV-формате.
-   `ui`: Пользовательский интерфейс, реализованный на JavaFX.

## 🚀 Сборка и запуск (без использования IDE)

Проект использует Gradle Wrapper, поэтому установка Gradle на компьютер не требуется.

### 1. Сборка проекта
Откройте терминал в корневой папке проекта и выполните команду:

-   Для Windows:
    ```bash
    gradlew.bat build
    ```
-   Для Linux / macOS:
    ```bash
    ./gradlew build
    ```

### 2. Запуск приложения
После успешной сборки запустите JavaFX-приложение командой `run` из Gradle:

-   Для Windows:
    ```bash
    gradlew.bat run
    ```
-   Для Linux / macOS:
    ```bash
    ./gradlew run
    ```

После запуска появится главное окно приложения.
